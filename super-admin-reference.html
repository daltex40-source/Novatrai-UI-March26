What Are Industry Profiles?

When a new tenant completes the onboarding wizard, they select one or more industry profiles. The profile engine (applyProfile() in admin.js) then dynamically relabels the sidebar navigation, renames pipeline stages, configures feature gates, and loads industry-specific templates — all without any code changes.

As a super admin, you need to understand exactly what each profile does so you can correctly configure tenants, troubleshoot label discrepancies, and advise clients on which profile fits their business.

Why does a client see "Renewals Tracker" instead of "Pipeline"?
They are on the Personal Lines insurance profile. The profile engine renames "Pipeline" to "Renewals Tracker", "Calendar" to "Renewals Calendar", and hides Companies and Invoices. This is by design — every label change you see is driven by the profile config in _novatraiProfileConfig. Use this document to identify which profile is active and what the expected naming should be.

Composite Profiles — Multi-Line Insurance

⭐ What Are Composite Profiles?

Insurance brokers often hold multiple lines of business — personal lines, life & investments, and commercial. When a tenant selects more than one insurance profile during onboarding, the system automatically builds a composite merged config using _buildCompositeConfig(). This combines features, sidebar items, and templates from all selected profiles into a single unified workspace.

Key composite rules:
• Features — if ANY selected profile enables a feature, the composite enables it.
• Sidebar — union of all items; if a screen is visible in any profile, it stays visible in the composite.
• Templates — all templates pooled (deduplicated by ID).
• Pipeline — when all 3 insurance lines are selected, uses a unified 6-stage master pipeline named "Full-Service Broker Pipeline". When 2 lines are selected, the pipeline shows tab views per line.

How to identify a composite tenant:
Check localStorage.getItem('novatrai_profile') in the browser console. A comma-separated value (e.g. personal_lines,life_invest) indicates a composite. A single value (e.g. personal_lines) indicates a single-profile tenant. The composite key is also reflected in document.body.dataset.profile.
